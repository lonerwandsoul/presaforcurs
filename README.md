## Структура презентации (15 слайдов)

1. Титульный — тема, автор, руководитель, скриншот интерфейса
2. Актуальность — «данные есть, системы нет», 2 дня на отчёт
3. Цель, объект, предмет, 6 задач
4. Объект автоматизации — процесс фабрики, проблемы «как есть», роли
5. Обоснование выбора — сравнение Excel / 1С / BI / заказной разработки
6. Архитектура — три уровня, стек
7. Модель данных — 10 таблиц, связи, демо-данные
8. Дашборд — 12 480 / 8,54 млн ₽ / 2,4 % / 87 %, прогноз
9. Производство и качество — выпуск по цехам, Парето по причинам брака
10. Финансы и продажи — прибыль, рентабельность, каналы
11. Операционные разделы — заказы и кадры
12. Отчётность, роли и безопасность — CSV, журнал, PDO/CSRF
13. Тестирование — 15 тест-кейсов, сверка расчётов
14. Результат — «2 дня → 5 минут», решённые задачи, перспективы
15. Спасибо за внимание — система в цифрах

Сделано по методическим указаниям кафедры: **12–15 слайдов MS PowerPoint, доклад 4–5 минут**,
с упором на цели и задачи, объект, содержание теоретической и практической части и оригинальные решения.

## Как пересобрать

```bash
pip install python-pptx python-docx pillow
python tools/build.py                      # только PPTX + PNG-превью
python - <<'EOF'                            # + заметки и речь
import sys, os; sys.path.insert(0, 'tools'); os.chdir('.')
import build; build.add_notes(); build.speech_md(); build.speech_docx()
EOF
```

Шрифт в PPTX — Segoe UI (есть на Windows, где будет защита). PNG-превью собраны
на DejaVu Sans, поэтому ширина строки в превью чуть отличается от PowerPoint —
вёрстка проверена с запасом, переносов и наложений нет.

## Рекомендации по шрифту при показе

Если на защитном компьютере нет Segoe UI, PowerPoint подставит системный шрифт —
текст останется читаемым, но заголовки станут чуть шире. Надёжнее всего
экспортировать в PDF (`Файл → Экспорт → PDF`) на своём компьютере и показывать PDF.
